Makes local copy of blog before writing anything. Mainly used for testing reasons. Use the commands below this one to push and deploy to website.

CD $home/documents/myblog; start-process http://localhost:8080/; npx @11ty/eleventy --serve

Publishes website to web host using Github actions and the command line. First deletes everything on web host with RClone, then builds the site, then publishes the site using Github.

Test enhancements with stop gaps and checks and an interactive commit message.

git config --global core.editor "notepad"; CD "$home/documents/myblog" && Start-Service ssh-agent -ErrorAction SilentlyContinue && rclone delete "$home/documents/myblog/DistSite" --rmdirs && rclone delete NFS: --rmdirs && npx @11ty/eleventy --quiet && git commit -a && git push; rclone delete "$home/documents/myblog/DistSite" --rmdirs

CD $home/documents/myblog; Start-Service ssh-agent; rclone delete $home/documents/myblog/DistSite --rmdirs; rclone delete NFS: --rmdirs; npx @11ty/eleventy --quiet; git add .; git commit -am (Read-Host "Enter commit message and press enter"); git push; rclone delete $home/documents/myblog/DistSite --rmdirs
